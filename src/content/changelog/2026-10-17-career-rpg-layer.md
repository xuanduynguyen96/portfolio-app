Added a gamified Career RPG layer on top of the existing design. Projects became quests with difficulty tiers and a single boss battle. Skills form a tree that levels up only through linked evidence. XP rules live in one config file with caps and diminishing returns, so padding the portfolio with tiny entries cannot inflate the score.
